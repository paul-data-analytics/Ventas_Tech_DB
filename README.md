# Pre-Entrega SQL - JOIN y UNION

## Base de datos utilizada
Ventas_Tech_DB
## Tablas utilizadas
- categorias
- clientes
- productos
- ventas
## Consultas JOIN
### JOIN 1
Relación entre ventas, clientes y productos.
### JOIN 2
Relación entre productos y categorías.
### JOIN 3
Total comprado por cliente.

## Consultas UNION
### UNION 1
Unión de nombres de clientes y productos.

### UNION 2
Clasificación de productos según precio y stock.

## Conclusión
Se aplicaron consultas JOIN para relacionar tablas mediante claves foráneas y consultas UNION para combinar resultados de diferentes conjuntos de datos.
